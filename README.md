# QQ for Switch

实验性 Nintendo Switch 自制客户端，当前测试版 **0.5.46-native4**。

![图标](assets/qq-for-switch.png)

仓库公开说明、图标和许可告知，Release 提供一个 NRO。应用实现源码、协议测试材料、私有组件适配、登录凭据和用户数据不在公开范围内；此仓库不是完整 NRO 的对应源码。

## 下载与使用

从 [0.5.46 测试版](https://github.com/shuiwen879867/QQ-for-Switch/releases/tag/v0.5.46) 下载 QQ-for-Switch-0.5.46-native4.nro，升级时替换 SD 卡上原 QQ 入口对应的 NRO。当前安装使用 /switch/switch_qq_watch.nro。当前构建仍依赖已有安装保存的完整设备身份，尚不支持全新 SD 卡直接初始化使用。

退出 DBI 后打开原 QQ 入口；需要登录时按提示完成。不要分享设备身份和会话文件。

## 本版视频授权修复

- 设备日志捕获两次旧式视频授权解析失败（-3），没有进入下载或解码；这不是 50 MB 下载上限触发。日志只有错误码，未保存服务器完整授权回复，不能断言真实失败全由某一种地址变体造成。
- 旧式视频授权使用消息真实发送者、当前账号和实际群号；私聊按私聊类型且不填群号，不再固定群号为 1。保留原视频文件标识与 MD5，声明大文件能力和 HTTPS 地址类型。
- 视频返回的是“地址前缀＋参数后缀”。现在保留前缀已有路径、查询和签名参数，再转为支持的 QQ HTTPS 视频主机；不再要求前缀只能是根路径，也不丢弃已有路径。
- 解析有符号服务器返回码，负数拒绝不会被误报为格式错误。失败提示显示正确的解析码、服务器码和读取阶段，保留聊天连接。
- 视频页的“重新获取”按钮和手柄 X 可重新申请授权，正在请求时不会重复提交；成功播放后原重新播放入口保留。
- 保留 50 MB（52,428,800 字节）视频下载上限；图片大小不受该上限影响，聊天图片不额外压缩。
- 大图打开时可接续聊天气泡已经开始的图片恢复请求，保持加载状态，避免重新出现失败提示或重复授权。
- 保留上版群历史大页面预算、按序号继续读取和历史视频/语音信息更新。

通过真实原生调度的合成回复回归和完整 URL/有符号错误码测试。本版尚未在 Switch 真实失败视频上确认授权及播放；安装完整读回证明文件正确，不能代替实际播放验证。

## 已有功能

- 内置 Twemoji 14.0.2 的 3,689 个 emoji 和 187 个常用 QQ 表情图形，文字绘制支持肤色、国旗、按键及 ZWJ 复合序列。QQ 编号依据原 QSid/EMCode 映射，解析普通小黄脸和 CommonElem 33/37。显示静态图形，缺少资源的表情保留名称；不代表所有新表情或动画播放。表情图形构建时缩放为 32px，不修改聊天原图。
- 常见平板横屏布局：导航侧栏、会话/联系人列表及右侧聊天或资料；触摸与手柄操作，系统中文输入法，深色和匿名显示模式。
- 好友资料、添加/删除、备注、消息和记录搜索；群资料、成员头像资料入口、成员搜索、群公告和按权限进行的禁言/管理等操作。匿名模式隐藏界面中自己的 QQ 号，不改变服务器身份。
- 手机/iPad QQ 的云端置顶同步、本地置顶与排序。无法解析的群消息保留原群归属，避免生成错误的数字私聊会话。
- 图片原图查看、缩放、拖动、重新加载和保存；聊天图片后台上传。文件收发入口已移除。GIF 显示首帧；支持语音播放，不含语音发送或通话。
- QQ 空间连续滚动、惯性及下一批动态后台预取；动态和详情的文字、图片、视频入口、评论和点赞状态。本人/好友空间、相册封面与照片，独立图文编辑界面、图片选择、评论及点赞/取消点赞。
- 空间凭据失效时保留聊天连接并允许刷新重试；读取失败保留现有内容。发表、评论及点赞等写操作必须服务器确认，失败保留草稿，不自动重发。
- 保留 0.5.40 的空间上传 HTTP 404 请求头修复及竖屏视频尺寸判断修复。聊天图片的下载大小及图片/视频尺寸、时长固定门槛已移除；视频下载按本次要求限制为 50 MB；实际处理仍受 Switch 可用内存、编码格式、网络及服务端权限约束。
- 自动登录、会话恢复和临时断线重连；未确认成功的发送不会自动重发。

## 验证与限制

本版通过严格 Switch 编译、2,125,063 条离线协议检查，实际消息解析器的群聊/私聊图片组合回归、NT 图片授权协议及原生调度回归、旧记录媒体更新和过期结果隔离，真实四线程图片加载及界面争用回归，超过 12 MB 的 HTTP 下载测试，空间实际响应回放和 23 张生产界面预览。

生产 HTTPS 代码经过本机 TLS 服务校验；生产视频解封装、H.264 解码和画面缩放使用真实竖屏 MP4 回放到结束。Switch 音频、实际帧率、新版聊天图片的真实服务兼容和长期稳定性仍需使用验证，不承诺手机 QQ 的速度或与 iPad QQ 逐像素一致。需要签名的请求仍独立签名，不能通用复用不同消息的签名结果。
