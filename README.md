# QQ for Switch

实验性 Nintendo Switch 自制客户端，当前测试版 **0.5.42-native4**。

![图标](assets/qq-for-switch.png)

仓库公开说明、图标和许可告知，Release 提供一个 NRO。应用实现源码、协议测试材料、私有组件适配、登录凭据和用户数据不在公开范围内；此仓库不是完整 NRO 的对应源码。

## 下载与使用

从 [0.5.42 测试版](https://github.com/shuiwen879867/QQ-for-Switch/releases/tag/v0.5.42) 下载 QQ-for-Switch-0.5.42-native4.nro，升级时替换 SD 卡上原 QQ 入口对应的 NRO。当前安装使用 /switch/switch_qq_watch.nro。当前构建仍依赖已有安装保存的完整设备身份，尚不支持全新 SD 卡直接初始化使用。

退出 DBI 后打开原 QQ 入口；需要登录时按提示完成。不要分享设备身份和会话文件。

## 本版图片修复

- 群聊和私聊优先使用消息携带的新式图片有效地址，避免旧式兼容字段生成的 MD5 地址遮盖它。
- 保留 multimedia.nt.qq.com.cn 下载主机和 rkey 等授权参数；相对 /download 地址使用对应主机，避免错误改写到旧式图片服务器。
- 有效的原始下载地址不再被缺少授权的备用字段覆盖。保留服务端提供的原图地址，不额外压缩图片；缩略图只为界面绘制缩放。
- 点击图片时缓存忙碌会保留打开请求，显示加载状态并在后续界面帧启动，不再误报加载任务无法启动。
- 修复界面忙碌时误取消仍可见图片下载的问题，保留四条后台下载通道、缓存和手动重新加载按钮。

设备图片日志中确有群图片 HTTP 404 和新式下载 HTTP 400。本版修复已发现的地址选择及取消缺陷；这些日志不含完整媒体地址，未逐张重放实际失败的聊天图片请求，也不保证修复过期链接或服务端拒绝授权。

## 已有功能

- 常见平板横屏布局：导航侧栏、会话/联系人列表及右侧聊天或资料；触摸与手柄操作，系统中文输入法，深色和匿名显示模式。
- 好友资料、添加/删除、备注、消息和记录搜索；群资料、成员头像资料入口、成员搜索、群公告和按权限进行的禁言/管理等操作。匿名模式隐藏界面中自己的 QQ 号，不改变服务器身份。
- 手机/iPad QQ 的云端置顶同步、本地置顶与排序。无法解析的群消息保留原群归属，避免生成错误的数字私聊会话。
- 图片原图查看、缩放、拖动、重新加载和保存；聊天图片后台上传。文件收发入口已移除。GIF 显示首帧；支持语音播放，不含语音发送或通话。
- QQ 空间连续滚动、惯性及下一批动态后台预取；动态和详情的文字、图片、视频入口、评论和点赞状态。本人/好友空间、相册封面与照片，独立图文编辑界面、图片选择、评论及点赞/取消点赞。
- 空间凭据失效时保留聊天连接并允许刷新重试；读取失败保留现有内容。发表、评论及点赞等写操作必须服务器确认，失败保留草稿，不自动重发。
- 保留 0.5.40 的空间上传 HTTP 404 请求头修复及竖屏视频尺寸判断修复。下载数据、图片尺寸、视频尺寸和时长的固定人为门槛已移除；实际处理仍受 Switch 可用内存、编码格式、网络及服务端权限约束。
- 自动登录、会话恢复和临时断线重连；未确认成功的发送不会自动重发。

## 验证与限制

本版通过严格 Switch 编译、2,125,063 条离线协议检查，实际消息解析器的群聊/私聊图片组合回归，真实四线程图片加载及界面争用回归，超过 12 MB 的 HTTP 下载测试，空间实际响应回放和 23 张生产界面预览。

生产 HTTPS 代码经过本机 TLS 服务校验；生产视频解封装、H.264 解码和画面缩放使用真实竖屏 MP4 回放到结束。Switch 音频、实际帧率、新版聊天图片的真实服务兼容和长期稳定性仍需使用验证，不承诺手机 QQ 的速度或与 iPad QQ 逐像素一致。需要签名的请求仍独立签名，不能通用复用不同消息的签名结果。
