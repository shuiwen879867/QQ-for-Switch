# QQ for Switch

Nintendo Switch 自制 QQ 客户端，支持聊天、图片、语音、视频和 QQ 空间。

## 安装与升级

1. 下载所选版本的 NRO，先备份原文件。
2. 将下载文件重命名为 `switch_qq_watch.nro`，替换 SD 卡 `/switch/switch_qq_watch.nro`。
3. 打开原 QQ 入口，按提示登录。

首次登录会为本机创建身份并向官方服务注册设备；已有完整记录会直接复用。注册失败后保留原身份，稍后重试。不要删除、复制或分享身份及会话文件。

0.5.46.4 已在 Switch 完成扫码登录。最新版保留注册修复和“发给自己”，0.5.59 增加文件上传确认兼容，并保留群文件大小与校验码修复；电脑端检查通过，文件收发与群文件浏览待真机验证。

## 功能与限制

- 触摸和手柄操作、中文输入、深色/匿名模式、好友与群资料、历史记录与置顶。
- 图片原图查看、保存与重载，语音播放、视频播放，emoji 和常用 QQ 表情。
- QQ 空间动态、相册、图文发布、评论和点赞。
- 最新版支持文件收发、群文件浏览和文件管理；兼容群文件大小与校验码格式，修复文件选择器只显示目录。
- 点击“发给自己”直接打开自己的普通聊天，可发送文字、图片和文件；取消指定设备选择。其他客户端的同步显示由 QQ 决定。
- 安装包在 QQ 内直接安装到 SD 卡，显示进度，按 B 取消。支持单内容清单的未压缩 NSP、XCI，保留已有内容；NSZ、XCZ 及多游戏合并包暂不支持。需要启动环境提供系统安装服务。

视频下载上限 50 MB；文件大小受 QQ 服务端与 SD 卡容量、文件系统约束。暂不支持空文件发送、语音发送或通话。网络、服务端权限和可用内存仍会影响功能。
