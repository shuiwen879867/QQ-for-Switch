# QQ for Switch

实验性 Nintendo Switch 自制客户端，当前测试版 **0.5.22**。

![图标](assets/qq-for-switch.png)

此仓库提供发行说明、图标和第三方许可文件。**不公开应用实现源码、腾讯源码、协议向量、私有组件适配或用户数据，也不是完整 NRO 的对应源码。** 本地工程与此公开仓库的范围不同。

## 下载与使用

从 [Releases](https://github.com/shuiwen879867/QQ-for-Switch/releases) 获取 NRO 测试版本，将其放入 SD 卡 `switch` 目录。当前构建仍依赖已有安装保存的完整设备身份，尚不支持全新 SD 卡直接初始化使用；请勿分享设备身份或会话文件。

- L / R 循环切换消息、好友、群聊，也可触摸标签；联系人和聊天记录可以滑动。
- 头像、群名片和图片直接显示；图片可点击放大、缩放和拖动。下载与解码在后台执行。
- 点输入框或按 A 使用系统输入法。收到语音后可点击播放，不含语音发送或通话。
- 设置中可切换自动登录、提示音、登出换账号。升级后须先成功登录一次，之后才有可恢复的会话。
- 二维码生成及扫码后显示预计完成百分比与剩余百分比；数值按阶段变化，服务端等待时不会伪造精确完成度。会话过期或服务端拒绝时需要重新登录。
- 临时断线按 2、5、10、20 秒最多重试四次，保留聊天，不自动重发未确认发送成功的消息。

## 0.5.22 修复

签名计算与原生回调使用独立线程，网络线程在计算期间继续收发消息、处理接收确认和心跳。原生执行采用安全基本块边界分片，减少每条指令的计数开销，保留执行范围、时间、指令上限和取消保护。每条请求仍生成自己的签名，不复用或跳过签名。

修复自己的群消息先到、发送回执后到时误断线的问题。完整到达的回复先处理再检查超时；异常发送回执只影响对应消息，不自动重发未确认消息。连续到达的消息按实际界面容量保留，避免队列溢出；界面每帧至少处理第一条待接收事件，联系人更新合并绘制。换账号或退出会取消旧任务并等待原生线程结束。

已通过离线协议、真实本地 TCP、真实后台线程、内存检查、阻塞签名期间收发和心跳、回执顺序、连续消息背压、安全分片，以及 Switch 编译。电脑原始库签名对照测量中耗时约下降 65%，**这不是 Switch 实测结果**。0.5.22 真机延迟、流畅度、重连和长期稳定性仍待实际使用验证。不承诺与最新版 iPad QQ 逐像素一致。

云端收藏最多 128 项；需重新上传的图片暂不支持。语音最长 120 秒、最大 3 MiB；缺少真实 QQNT UID 的部分新式私聊语音暂不支持。图片支持 PNG、JPEG、GIF 首帧。
