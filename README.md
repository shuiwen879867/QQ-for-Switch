# QQ for Switch

实验性 Nintendo Switch 自制客户端，当前测试版 **0.5.23**。

![图标](assets/qq-for-switch.png)

此仓库提供发行说明、图标和第三方许可文件。**不公开应用实现源码、腾讯源码、协议向量、私有组件适配或用户数据，也不是完整 NRO 的对应源码。** 本地工程与此公开仓库的范围不同。

## 下载与使用

从 [Releases](https://github.com/shuiwen879867/QQ-for-Switch/releases) 获取 NRO 测试版本，将其放入 SD 卡 `switch` 目录。当前构建仍依赖已有安装保存的完整设备身份，尚不支持全新 SD 卡直接初始化使用；请勿分享设备身份或会话文件。

- L / R 循环切换消息、好友、群聊，也可触摸标签；联系人和聊天记录可以滑动。
- 头像、群名片和图片直接显示；图片可点击放大、缩放和拖动。下载与解码在后台执行。
- 点输入框或按 A 使用系统输入法。收到语音后可点击播放，不含语音发送或通话。
- 设置中可切换自动登录、提示音、登出换账号。升级后须先成功登录一次，之后才有可恢复的会话。
- 二维码生成及扫码后显示预计完成百分比与剩余百分比；数值按阶段变化，服务端等待时不会伪造精确完成度。会话过期或服务端拒绝时需要重新登录。
- 临时断线按 2、5、10、20 秒最多重试四次，保留聊天，不自动重发未确认发送成功的消息。

## 0.5.23 改进

- 无法解析的消息内容显示 **【无法解析的消息，请在手机QQ上查看】**；无法确认聊天身份时显示提示。私聊同步解析失败保留连接并延迟重试，避免内容不兼容触发断线。
- 云端收藏从后向前显示，保留最新128项。频繁群通知合并为延迟刷新，减少反复重载好友和群聊。
- 向上滑动到顶部加载服务器保留的更早记录，每页最多20条，保持阅读位置并去重。最多保留128条，不保证取回手机本地全部记录。
- 点“图片”选择系统相册或已保存照片，再点“发送所选图片”或按A发送。后台读取及上传，不以连接关闭代替成功回执；最多列出64张，支持3MiB以内的JPEG、PNG、GIF。
- 收到图片放大后可点“保存到相册”或按Y；系统服务确认成功才显示相册保存成功。同时尝试保存原图到SD卡 `switch/QQ-for-Switch/Photos`，失败会分别提示。
- 预览与放大复用压缩图片缓存；图片解码与签名分开使用处理核心。保护共享解码内存预算，下载、保存、上传不占用界面线程。

已通过离线协议、内存检查、真实线程和本地TCP上传、超时/断线/错误回执、消息兜底、历史合并及Switch编译。**0.5.23真机照片上传、相册保存、服务器历史兼容、延迟和长期稳定性仍待实际使用验证**，不承诺与最新版iPad QQ逐像素一致。每条需要签名的请求仍生成独立签名。

收藏表情需要重新上传的情况仍有限制；部分QQNT图片授权暂不支持。语音最长120秒、最大3MiB，缺少真实QQNT UID的部分新式私聊语音暂不支持。不含语音发送或通话。GIF显示首帧。
